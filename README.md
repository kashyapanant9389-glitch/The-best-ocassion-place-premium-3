# The Best Occasion Place — GitHub Website

Premium responsive static website for **The Best Occasion Place, Dehradun**.

## Publish on GitHub Pages
1. Create a new GitHub repository, e.g. `the-best-occasion-place`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under Source choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. After GitHub publishes it, your website URL will look like:
   `https://YOUR-USERNAME.github.io/the-best-occasion-place/`

## Customize
Edit the business name, menu, images, address, and phone in `index.html`.
The current menu/prices are demo content and should be replaced with the client's actual details.
